# Implementation plans

Use this directory for implementation plans that are intended to guide future or in-progress repository work.

A plan should be specific enough that another contributor or coding agent can execute it without relying on hidden conversation context.

## Recommended contents

- Goal and scope.
- Relevant architecture/context links.
- Exact files expected to change.
- Compatibility constraints (`net48`, `net8.0-windows`, public API expectations).
- Step-by-step implementation tasks.
- Test/validation commands.
- Documentation and migration impact.
- Explicit out-of-scope items when useful.

Plans are working documents, not a substitute for canonical architecture or development documentation. Once behavior is implemented, update the appropriate `docs/architecture/`, `docs/development/`, `docs/maintenance/`, or `docs/migration/` document if the stable repository model changed.
