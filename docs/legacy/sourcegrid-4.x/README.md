# Archived SourceGrid 4.x documentation

This directory preserves the historical SourceGrid documentation and its original assets.

## Status

**Historical / non-canonical.** The archived HTML identifies itself as SourceGrid library version 4.30, documentation version 2.3, and contains instructions from the .NET 2 / Visual Studio 2005 / CodePlex era.

Do not use this material to determine current:

- target frameworks or SDK requirements;
- package/dependency versions;
- repository/download locations;
- build/test commands;
- SourceGrid 5.0 migration requirements.

Use the current documentation index at `../../README.md` and the repository root `README.md` instead.

## Preserved files

`SourceGrid_EN.html`, `style.css`, and all image/logo assets from the former root `Documents/` directory are preserved together so the original relative asset references continue to work.

The files are intentionally not rewritten to modern terminology. Their value is historical API usage context and examples.

The former `Documents/MIGRATION-5.0.md` is **not** archived here because it is current SourceGrid 5.0 material. It now lives at `../../migration/5.0.md`.
